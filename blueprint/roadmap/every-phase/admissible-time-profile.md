# Admissible time profile

Let $\mathcal S(\mathbb R)$ be the complex vector space of Schwartz functions
$f : \mathbb R \to \mathbb C$ on the real line. A Schwartz function
$f \in \mathcal S(\mathbb R)$ is an **admissible time profile** when the
following three conditions hold.

1. *Real values.* $f$ takes real values: $\operatorname{Re} f(t) = f(t)$ for
   every $t \in \mathbb R$.
2. *Compact support.* $f$ has compact support.
3. *Unit integral.* $\int_{\mathbb R} f(t)\, dt = 1$.

The integral is the Lebesgue integral over the real line. Since $f$ is a
Schwartz function it is infinitely differentiable, so an admissible time
profile is a real-valued, infinitely differentiable, compactly supported
function of time with integral $1$, regarded as a complex-valued Schwartz
function.
